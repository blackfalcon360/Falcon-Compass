# Falcon Compass

Full-screen flat-mode compass with live coordinates. Works in portrait and landscape.
White translucent background, splash screen "Brought to You By: / Black Falcon".

By: Black Falcon

## Build
- Push this folder to GitHub. The "Build APK" workflow (Actions tab) builds the APK and
  uploads it as an artifact named FalconCompass-APK.
- Or open the folder in Android Studio and press Run.
